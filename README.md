# قاصدک در برابر جاسوس — شبیه‌سازی پویا و چالش حریم خصوصی

پیاده‌سازی پروژهٔ پایانی درس شبکه‌های کامپیوتری (۴۰۴۴۳).
هر گره یک **پردازهٔ مستقل سیستم‌عامل** است که روی یک **پورت UDP اختصاصی** روی
`127.0.0.1` کار می‌کند و تمام ورودی/خروجی آن **ناهم‌زمان (asyncio)** است.

---

## اجرا

```bash
cd Code
python3 -m pip install -r requirements.txt

python3 -m src.experiments all     # کل کارزار آزمایش‌ها (حدود ۱۵ دقیقه)
python3 -m src.plots               # نمودارها و جدول‌ها
python3 -m src.verify              # بررسی‌های صحت روی همهٔ اجراها
```

مراحل به‌صورت جداگانه نیز قابل اجرا هستند:

```bash
python3 -m src.experiments topology    # فقط تولید و اعتبارسنجی توپولوژی
python3 -m src.experiments calibrate   # انتخاب تعداد و مکان بهینهٔ جاسوس‌ها
python3 -m src.experiments simulate    # اجرای فازهای ۱ تا ۵
python3 -m src.experiments analyse     # محاسبهٔ معیارها
```

یک اجرای کوچک و سریع برای نمایش زنده (مناسب ویدئو):

```bash
python3 -m src.demo --mode dandelion --p 0.5 --packets 20
```

## ساختار کد

| فایل | نقش |
|------|-----|
| `src/topology.py` | تولید توپولوژی فضایی (۱۰۰۰×۱۰۰۰)، خوشه‌بندی، اتصال چندگانه، تأخیر پایه |
| `src/graphutil.py` | ابزارهای گراف: همبندی، پل، دایکسترا (بدون کتابخانهٔ بیرونی) |
| `src/node.py` | **پردازهٔ گره**: سوکت UDP، مجموعهٔ Seen، پخش عمومی و ماشین حالت Dandelion |
| `src/controller.py` | ارکستراتور: اجرای پردازه‌ها، تزریق ۲۰۰ بسته، جمع‌آوری لاگ مرجع |
| `src/adversary.py` | مدل شبکهٔ مهاجم، هستهٔ گشت تصادفی، تخمین‌گرها و انتخاب جاسوس |
| `src/analysis.py` | معیارهای T80٪، دقت، Score_adv و Score_honest |
| `src/experiments.py` | کارزار آزمایش‌ها (فاز ۱ تا ۵، پنج بذر، جاروب p) |
| `src/plots.py` | نمودارها و جدول‌های گزارش |
| `src/verify.py` | بررسی‌های خودکار صحت پروتکل و مدل تأخیر |
| `src/demo.py` | اجرای کوچک و پرگو برای نمایش |

## قرارداد روی سیم

تنها چیزی که روی UDP منتقل می‌شود:

```
<packet-id>|<S یا F>
```

شناسهٔ گره مبدأ و زمان تولید بسته **هرگز** منتقل نمی‌شوند؛ این دو فقط در لاگ
مرجع شبیه‌ساز (`meta.json`) ثبت می‌شوند. گرهٔ فرستندهٔ قبلی صرفاً از روی آدرس
مبدأ دیتاگرام UDP شناخته می‌شود — دقیقاً مانند شبکهٔ واقعی.

## خروجی‌ها

```
results/
  topology.json            توپولوژی ثابت همهٔ آزمایش‌ها + گزارش اعتبارسنجی
  calib/calibration.json   انتخاب تعداد بهینهٔ جاسوس‌ها
  runs/<tag>/events.jsonl  لاگ مرجع هر اجرا (همهٔ رویدادهای همهٔ گره‌ها)
  runs/<tag>/meta.json     پیکربندی اجرا + مبدأ و زمان واقعی هر بسته
  results.json             همهٔ معیارها (میانگین/میانه/انحراف معیار)
  figures/*.png            نمودارها
  tables/tables.md         جدول‌های گزارش
  verification.json        نتیجهٔ بررسی‌های صحت
```
